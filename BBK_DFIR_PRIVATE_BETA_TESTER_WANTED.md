# BBK-DFIR Controlled Private Beta — Independent Tester Wanted

BBK-DFIR is a local/offline-first Windows DFIR analysis tool currently in a controlled private beta.

I am looking for **one independent tester** who can run the current private-beta build in a separate Windows environment and return direct technical/usability feedback.

## What I need

A tester who can:

- use an isolated Windows 10/11 VM or separate Windows test machine;
- install and start the private-beta build;
- analyze the provided sample Windows event data;
- report what actually happened;
- return one of:
  - **PASS**
  - **PASS WITH ISSUES**
  - **FAIL**
- include errors, screenshots, or short notes when useful.

The expected hands-on time is roughly **30–60 minutes**.

## What you do NOT need

- No real incident or customer evidence.
- No production environment.
- No purchase or commercial commitment.
- No marketing, testimonial, endorsement, or public promotion.
- No source-code review is required.
- You do not need to be a well-known DFIR researcher.

A hands-on Windows/DFIR practitioner or small-tool developer is preferred.

## What I provide

Approved testers receive private read access to a separate distribution repository containing:

- the Windows private-beta installer;
- a short test checklist;
- sample Windows event data;
- a time-limited test license;
- SHA-256 integrity information.

The installer currently uses a **self-signed private-beta publisher certificate**. It is not publicly trusted and is not a commercial/public release.

## Privacy and evidence boundary

Please do not use confidential, customer, employer, or live-case evidence.

The supplied sample data is sufficient for the requested test.

Any returned evidence used for the beta record will be limited to the observed product behavior and will be sanitized before being retained.

## How to volunteer

Comment **“Interested”** on the public tester-recruitment issue in this repository.

If selected, I will add your GitHub account with **read-only access** to the separate private distribution repository.

No follow-up is expected if you are not interested or do not have time.

## Test result boundary

This is an independent product test, not a customer engagement and not proof of commercial demand, willingness to pay, or production readiness.

BBK-DFIR remains a controlled private-beta product until its separate release gates are satisfied.
